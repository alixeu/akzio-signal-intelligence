## 主要发现

- **Paper 执行控制应先修。** 已开始的异步调度可能在冻结后继续发送新订单或改价，冻结还可能阻断既有订单的普通对账。部分提交的收束和旧 Run 恢复时的审批绑定也有缺口。见 T01–T03、T34。[Paper 调度](../crates/akzio-execution/src/paper_dispatch.rs#L226) · [报单顺序](../crates/akzio-execution/src/paper/execute.rs#L111) · [发送授权](../crates/akzio-execution/src/paper/submission_authorization.rs#L157)
- **预测、评分和校准须先统一标签。** 盘中生成的 T1 期限可落在当天，Outcome 从基准交易日之后开始计数。Outcome 评分和校准的价格锚也不同，同一预测的真实标签可能反号。历史模型版本还会被本次配置覆盖。见 T04–T08。[期限绑定](../crates/akzio-research/src/agent/structured.rs#L184) · [Outcome 采集](../crates/akzio-daemon/src/outcome/collection.rs#L43) · [校准采集](../crates/akzio-cli/src/cli/calibration.rs#L1063)
- **学习晋级存在多处阻断。** 正式流程缺独立风险真值的生产调用，学习还要求当前正式新闻无法满足的方向覆盖。Canary 要求每对都有尾损，最长五日的 Outcome 达不到单窗 ES 的 20 个样本要求。见 T09–T11、T36–T38。[风险真值](../crates/akzio-learning/src/evaluation/risk_ground_truth.rs#L59) · [学习覆盖](../crates/akzio-domain/src/decision.rs#L1373) · [Canary 门槛](../crates/akzio-learning/src/campaign.rs#L307)

## 待办优先级

P0 处理紧急执行控制。P1 涉及订单收束、策略有效性、学习闭环或关键审计证据。P2 用于补齐研究验证与运营能力。P3 处理维护与文档一致性。

### P0

- [x] **T01 将冻结落实到每次 Paper 写入边界。** 调度入口只在发起异步 Broker 流程之前检查 FreezeState，正式 transport 的提交/改价 guard 另查取消和日志。普通对账也经同一冻结检查。定义冻结水位和在途请求的处置，冻结后保留已持久化效果的只读对账与既有保护性撤单边界。验收覆盖在报价或资格查询等待中冻结、多订单间冻结和已有订单恢复，确认冻结水位后的新 POST/PATCH 计数为零，已发请求仍可追踪到原 ID。[调度](../crates/akzio-execution/src/paper_dispatch.rs#L252) · [写入 guard](../crates/akzio-cli/src/cli/run_commands.rs#L263) · [对账分流](../crates/akzio-daemon/src/dispatch.rs#L274)
