# 中文注释覆盖登记

## 记录规则

本表以任务开始时 Git 清单为基线，并把每个路径单独登记；当前仓库共登记 499 个路径（其中两份本任务文档为新增路径）。worker 只负责明确写入范围，主 Agent 负责清单、跨模块语义、专用文档、差异审计和最终验证。

状态含义：

- **已完成**：文件已完整阅读，函数/方法/trait 默认实现/宏/闭包/异步任务/测试或配置分支已复核，并实际补充合法普通中文注释。
- **受限文件已补外部说明**：文件是运行时 Prompt、模板、SQL、历史 fixture 或不支持安全注释的结构化输入；原文保持不变，本表记录用途、消费方、关联入口和不能修改的原因。
- **排除**：第三方、二进制、纯生成文件、锁文件、视觉资源、版本控制元数据或普通说明文档；排除项不计入已注释数量。
- **未完成**：尚未达到上述标准；最终报告必须保留原因。

普通注释不得改变表达式、控制流、签名、类型、依赖、SQL、Prompt、fixture、配置值、日志或测试断言；不新增或改写 ///、//!、#[doc]。

## 特殊文件边界

- crates/akzio-research/src/agent/prompts/**、crates/akzio-ingest/src/prompts/**：由 include_str! 或 Prompt registry 读取的运行时文本；不能因扩展名是 Markdown/文本就改写。相关 Rust 消费方已补注释，本表登记原文用途和限制。
- crates/akzio-store/src/store/fixtures/**：历史完整性/退休协议输入；不能改 SQL 或历史文本，测试与 Store 代码说明写在源码外。
- config/research-quality-cases.json、Info.plist.in 等严格结构化/生成输入：不插入非法注释，保持字段和模板替换语义。
- Cargo.lock、图片、SVG、ICNS、PNG、.gitignore、.gitattributes：排除。
- README、AGENTS 和既有 docs：说明文档/规则，不用源码注释数量冒充覆盖；运行时契约仍按任务要求读取。
